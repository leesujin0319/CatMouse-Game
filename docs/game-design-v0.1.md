# 쥐생역전: 찍찍런

> 치즈를 빼앗긴 작은 쥐가 화면 안을 자유롭게 위아래로 오가며 고양이 군단을 물리치고, 먹은 치즈로 전투 방식을 진화시키는 2D 자동 전투 로그라이크 러너.

## 1. 문서 목적과 제출 목표

이 문서는 NAN 2026 사전 과제용 게임 기획의 기준 문서다. 구현·아트·AI 활용 문서는 이 문서를 기준으로 분리 작성한다.

| 항목 | 결정 |
| --- | --- |
| 제출 우선 플랫폼 | PC WebGL / GitHub Pages |
| 보조 플랫폼 | Android APK (WebGL 검증 뒤 선택) |
| 1회 플레이 목표 | 2~4분 |
| 영상 목표 | 첫 45초 안에 이동, 자동 공격, 레벨업, 스킬, 엘리트 전투를 모두 보여 준다. |
| 플레이 감정 | 작고 약한 쥐가 빠르게 강해져 고양이를 역전하는 쾌감 |

WebGL 빌드와 전체 소스는 같은 공개 저장소에 둔다. 게임은 인터넷, 유료 라이선스, API 키 없이 실행 가능해야 한다.

## 2. 레퍼런스 분석과 독자성 원칙

`LAB Escape!`는 달리기 중 자원을 얻고 무작위 성장 선택으로 강해지는 러너 로그라이크 리듬을 보여 준다. 이 프로젝트는 그 **장르적 리듬**만 참고한다.

### 참고할 요소

- 짧은 조작으로 즉시 이해되는 자동 전진 구조
- 적 처치 또는 회피와 성장 자원의 연결
- 한 판 안에서 빌드가 달라지는 선택의 재미
- 거리·체력·자원처럼 한눈에 읽히는 HUD

### 사용하지 않을 요소

- 레퍼런스의 캐릭터, 연구소 배경, 적 디자인, 모자·변이 카드 표현, UI 배치, 사운드, 애니메이션, 스테이지 구성을 복제하지 않는다.
- 스크린샷 트레이싱, 데이터 추출, 코드·에셋 전용, 유사한 명칭 사용을 금지한다.
- 외부 에셋과 AI 생성 에셋은 출처·라이선스·프롬프트·인간 수정 내역을 별도 자산 대장에 기록한다.

### 우리 게임의 고유한 세 가지 기둥

1. **세로 자유 이동 회수전**: 좌우 이동 없이 화면 안에서 자유롭게 위아래로 움직여 치즈를 회수하고 공격을 피한다.
2. **치즈 진화**: 치즈는 경험치이면서 쥐의 외형·무기·스킬을 바꾸는 서사적 성장 자원이다.
3. **고양이의 동선 압박**: 고양이는 단순 체력 덩어리가 아니라 이동 경로를 막거나 돌진·투사체로 순간적인 회피 결정을 만든다.

## 3. 세계관과 플레이어 판타지

동화풍 식료품 저장실의 비상 치즈 저장고가 고양이 군단에게 약탈당했다. 플레이어는 찻잔·밀가루 포대·통조림 사이를 달리는 마지막 배달 쥐가 되어 빼앗긴 치즈를 회수하고, 치즈에 깃든 힘으로 진화해 고양이 대장을 쓰러뜨린다.

- **플레이어**: 빠르지만 약한 배달 쥐
- **적**: 치즈를 독점하고 이동 경로를 위협하는 고양이 군단
- **무기**: 쥐가 모아 둔 도토리 발사기
- **성장 재화**: 회수한 치즈
- **승리 판타지**: 도망치던 쥐가 빌드를 완성해 거대한 고양이를 밀어내는 역전

## 4. 핵심 게임 루프

```text
자동 전진
  → 고양이와 장애물이 화면의 다양한 높이에 등장
  → 도토리 자동 공격 + 위/아래 이동으로 회피·회수
  → 치즈 획득
  → 경험치 누적 및 레벨업
  → 능력 셋 중 하나 선택
  → 적 조합과 이동 압박 강화
  → 엘리트/보스 처치 또는 체력 소진
```

플레이어의 목표는 가장 멀리 달리는 것만이 아니다. 위험한 높이에 놓인 치즈를 회수해 다음 레벨업을 앞당기고, 자기 빌드에 맞는 능력을 선택해 고양이 압박을 역전해야 한다.

## 5. 조작과 화면

### 조작

| 입력 | PC WebGL | 모바일 | 결과 |
| --- | --- | --- |
| 위 이동 | `W` / `↑` 길게 입력 | 위로 드래그 | 화면 상단 방향으로 연속 이동 |
| 아래 이동 | `S` / `↓` 길게 입력 | 아래로 드래그 | 화면 하단 방향으로 연속 이동 |
| 액티브 스킬 | `Space` | 우측 하단 버튼 | 현재 빌드의 액티브 스킬 사용 |
| 일시정지 | `Esc` | 일시정지 버튼 | 게임 일시정지 |

좌우 입력은 없다. 플레이어는 화면 왼쪽 35% 지점에 유지되고, 플레이 영역의 상·하 경계 안에서 자유롭게 움직인다. 배경·적·치즈는 오른쪽에서 왼쪽으로 흘러온다.

### HUD

- 좌측 상단: 체력, 일시정지
- 상단 중앙: 거리, 현재 레벨, 경험치 바
- 우측 상단: 회수 치즈 수, 액티브 스킬 쿨타임
- 레벨업 시: 화면을 일시 정지하고 능력 카드 3개를 제시

HUD는 레퍼런스의 구성을 모사하지 않고, 아이콘·색·폰트·배치를 독자적으로 설계한다.

## 6. 플레이 시스템

### 6.1 플레이어와 기본 공격

가장 가까운 적에게 도토리를 자동 발사한다.

| 초기값 | 설계 초안 |
| --- | --- |
| 체력 | 5칸 |
| 이동 범위 | 플레이 영역 안에서 자유로운 세로 이동 |
| 공격 | 도토리 1발, 단일 대상 |
| 공격 간격 | 0.75초 |
| 치즈 획득 | 닿으면 즉시 획득 |

수치는 밸런싱용 가설이며, WebGL 플레이테스트 후 조정한다.

### 6.2 치즈와 진화

- 일반 고양이는 경험치 치즈를 1~3개 떨어뜨린다.
- 치즈를 모아 레벨업하면 능력 3개 중 하나를 선택한다.
- 레벨 3, 6, 9에서 외형과 무기 효과가 변하는 **치즈 진화 단계**를 연출한다.
- 진화는 별도 선택이 아니라 현재 빌드의 누적 결과여야 한다. 예: 관통 빌드가 많으면 도토리 주머니가 커지고, 드론 빌드가 많으면 치즈 배낭이 기계화된다.

### 6.3 세로 동선 압박

적과 치즈는 플레이 영역의 다양한 높이에 배치된다. 플레이어는 안전한 높이로 피할 수 있지만, 성장에 필요한 치즈는 위험한 동선에 놓일 수 있다.

- 적의 충돌 영역에 닿으면 피해를 받는다.
- 투사체와 돌진은 목표 경로 또는 위험 영역을 사전 경고한 뒤 발동한다.
- 플레이어는 별도 이동 단계·스태미나·이동 쿨다운 없이 연속 이동한다.
- 모든 위험은 최소 0.5초 전에 읽을 수 있어야 한다.

## 7. 콘텐츠 범위

### 사전 과제 MVP: 반드시 구현

#### 아트·공간 기준: 동화풍 식료품 저장실

- 배경은 따뜻한 목재 선반, 유리병, 곡물 자루, 차 상자, 쿠키 통처럼 읽기 쉬운 식료품 소품으로 구성한다.
- 선반의 높이와 식재료 상자는 배경 연출로만 사용한다. 플레이 영역은 상·하 경계와 충분한 여백으로 읽히게 하며, 위험 요소와 회수 대상은 배경 소품보다 항상 앞에서 읽혀야 한다.
- 도토리·치즈·고양이의 실루엣을 우선하고, 특정 레퍼런스의 연구소·실험 장비·색 구성·UI 인상을 사용하지 않는다.
- 배경 타일은 화면 반복 시 이음새가 드러나지 않도록 원경·중경·근경의 세 레이어 패럴랙스로 제작한다.

| 분류 | 구현 범위 |
| --- | --- |
| 맵 | 동화풍 식료품 저장실 1종, 원경·중경·근경 반복 타일 3종 |
| 일반 적 | 아기 고양이(기본), 검은 고양이(돌진), 삼색 고양이(투사체) |
| 엘리트 | 갑옷 고양이(보호막 또는 높은 체력) |
| 보스 | 고양이 대장 1종, 세로 위험 구역 점령 패턴 2개 |
| 패시브 능력 | 8개 |
| 액티브 스킬 | 2개 |
| 진화 | 레벨 3/6의 2단계 시각 변화 |
| 화면 | 타이틀, 인게임, 레벨업, 결과 |
| 기록 | 생존 시간, 거리, 처치 수, 치즈 수, 최고 레벨 |

### 제출 뒤 확장 후보: 구현하지 않아도 되는 항목

- 거실·주방·침실·다락방·정원으로 이어지는 다중 바이옴
- 샴고양이·닌자 고양이·마법사 고양이 등 적 다양화
- 업적, 다수 액티브 스킬, 보스 3종, Android 빌드

MVP에 없는 항목은 문서나 영상에서 완성 기능처럼 제시하지 않는다.

## 8. 능력 설계

능력은 카드의 외형보다 **전투 결과가 눈에 보이도록** 만든다. 동일 능력은 최대 2회까지만 중첩한다.

| 분류 | 능력 | 1회 효과 | 빌드 역할 |
| --- | --- | --- | --- |
| 공격 | 쌍도토리 | 발사체 +1 | 다중 타격 |
| 공격 | 관통 껍질 | 적 1명 관통 | 직선 정리 |
| 공격 | 밤송이 폭발 | 적 처치 시 소형 폭발 | 군중 처리 |
| 공격 | 유도 도토리 | 가까운 적 방향으로 회전 | 세로 조준 보정 |
| 공격 | 와인더 | 플레이어 주위를 도는 도토리 | 근접 방어 |
| 생존 | 치즈 자석 | 회수 반경 증가 | 위험 동선 부담 감소 |
| 생존 | 도토리 조끼 | 최대 체력 +1 | 실수 완화 |
| 특수 | 치즈 드론 | 일정 주기 보조 공격 | 지속 피해 |

### 액티브 스킬

| 스킬 | 효과 | 의도 |
| --- | --- | --- |
| 찍찍 대시 | 짧은 무적 상태로 전방을 가로지르며 적을 밀어낸다. | 위기 탈출 |
| 치즈 미끼 | 지정 높이에 치즈 덩어리를 던져 고양이의 이동을 유도하고 폭발시킨다. | 동선 재배치와 군중 제어 |

첫 번째 영상용 빌드에서는 `쌍도토리 + 관통 껍질 + 치즈 자석 + 찍찍 대시` 조합이 45초 안에 읽히도록 한다.

## 9. 적과 난이도

| 적 | 행동 | 대응 |
| --- | --- | --- |
| 아기 고양이 | 현재 높이를 유지하며 접근 | 자동 공격으로 처치 |
| 검은 고양이 | 경고 후 목표 높이를 향해 직선 돌진 | 위아래로 이동해 경로 이탈 |
| 삼색 고양이 | 원거리 털뭉치 발사 | 경고 타이밍에 회피 |
| 갑옷 고양이 | 보호막을 두른 채 전진 | 관통·폭발 또는 장기 화력 |
| 고양이 대장 | 두 개의 세로 위험 구역을 잠시 점령하고 소환 | 안전한 높이로 이동하고 액티브 스킬 사용 |

난이도는 단순 체력 증가만으로 올리지 않는다. 거리 구간에 따라 적 조합, 치즈 배치, 세로 위험 경고 수와 이동 폭을 조절한다.

| 거리 | 목적 | 예시 |
| --- | --- | --- |
| 0~150m | 조작 학습 | 기본 적 + 안전한 치즈 배치 |
| 150~400m | 첫 빌드 완성 | 돌진 적과 엘리트 등장 |
| 400m~ | 세로 동선 판단 시험 | 투사체·돌진 혼합, 보스 예고 |

## 10. 게임 종료와 결과

체력이 0이면 즉시 종료한다. 결과 화면에는 다음만 명확히 보여 준다.

- 생존 시간
- 이동 거리
- 처치한 고양이 수
- 획득 치즈 수
- 최고 레벨
- 이번 판의 선택 능력 아이콘
- `다시 달리기` 버튼

영구 성장과 저장은 장기 로드맵의 확정 기능이다. 사전 과제 빌드에서는 심사 플레이를 반복 노가다에 묶지 않도록, 영구 성장 화면의 실제 제공 여부를 코어 러닝 루프와 WebGL 검증 뒤에 결정한다. 다만 저장·보상·강화의 기술 경계는 처음부터 유지하며, 결과 화면은 메타 보상으로 이어질 수 있어야 한다.

## 11. AI 활용 방향과 안전장치

AI 활용은 나중의 기술 문서에서 재현 가능하게 설명한다. 게임의 실행 가능성은 외부 AI 서비스에 의존하지 않는다.

### 제작 단계 AI 활용

- 기획 초안·밸런스 가설·테스트 케이스 보조
- 콘셉트 탐색용 이미지·아이콘 초안 생성 후 사람의 수정과 Unity 최적화
- 코드 구조 초안·테스트 보조 후 사람의 리뷰와 플레이 검증

### 런타임 AI 디렉터: 기술 파운데이션 후보

매 프레임 생성형 AI를 호출하지 않는다. 20초마다 플레이 텔레메트리(체력, 세로 이동량, 치즈 회수율, 선택 빌드)를 요약해, 미리 제작한 조우 카드 중 하나를 선택하는 **제약형 디렉터**로 설계한다.

- 입력: 집계된 플레이 로그
- 출력: 허용된 JSON 조우 카드 ID와 난이도 가중치
- 검증: 스키마 검사와 최대 난이도 제한
- 실패 시: 규칙 기반 조우 선택기로 즉시 폴백

이 구조는 AI 활용을 보여 주면서도 WebGL 심사 환경에서 네트워크·키·응답 지연으로 게임이 멈추지 않게 한다.
