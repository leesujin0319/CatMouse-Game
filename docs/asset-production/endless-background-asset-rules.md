# 무한 횡스크롤 배경 에셋 제작 규칙

## 적용 범위

이 규칙은 `쥐생역전: 찍찍런`의 식료품 저장실 배경, 이동 바닥, 근경 벽과 장식 소품에 적용합니다. 모든 에셋은 한 화면을 위한 일러스트가 아니라, 임의 횟수로 좌우 반복되는 게임 리소스로 제작합니다.

## 공통 반복 규칙

1. 각 타일의 왼쪽·오른쪽 12~15%는 **연속 구간**으로 둡니다.
2. 연속 구간에는 문, 기둥, 선반, 상자, 치즈, 식물, 강한 그림자, 큰 균열처럼 경계를 드러내는 요소를 배치하지 않습니다.
3. 양쪽 연속 구간은 같은 높이·색·광원·재질·선 리듬을 사용합니다.
4. 고유 오브젝트와 장식 밀도 변화는 중앙 70~76%에만 배치합니다.
5. 타일 가장자리에서 잘린 오브젝트를 사용하지 않습니다.
6. Unity에서는 최소 3개 타일을 나란히 배치하고, 모든 이음새를 실제 게임 카메라로 검수합니다.

## 3파트 역할 분리

| 파트 | 포함 요소 | 반복 방식 | 금지 사항 |
| --- | --- | --- | --- |
| 배경 | 상단 벽, 옅은 질감, 낮은 밀도의 선반 | 바닥과 같은 속도로 수평 반복 | 바닥·근경 소품을 함께 굽기 |
| 바닥 | 넓은 중앙 이동 영역, 저대비 타일·그라우트 | 배경과 같은 속도로 수평 반복 | 가장자리의 랜드마크, 좁은 플랫폼 형태 |
| 근경 | 하단 벽체·레일과 별도 장식 소품 | 배경·바닥과 같은 속도로 수평 반복 | 소품 군집을 베이스 타일에 고정해 반복시키기 |

식료품 저장실 내부가 하나의 고정된 공간으로 보이도록 세 파트의 기본 이동 배율은 모두 `1`을 사용합니다. 별도의 공간이나 연출 구간이 확정되기 전에는 파트별 패럴랙스 차이를 적용하지 않습니다.

## 근경 소품 규칙

- 근경 벽 타일은 비어 있는 반복 베이스로 유지합니다.
- 상자, 병, 치즈, 화분 같은 소품은 투명 스프라이트로 분리합니다.
- 런타임에서 시드 기반으로 종류·간격·좌우 반전·높이를 바꾸며 재배치합니다.
- 빠른 횡스크롤을 고려해 화면 내 동시 노출 수를 낮게 유지하고, 중앙 전투 공간을 가리지 않습니다.

## 세로 카메라 여유

- 각 파트의 높이와 겹침은 [`../gameplay-size-standard-v0.1.md`](../gameplay-size-standard-v0.1.md)의 월드 유닛 기준을 따릅니다.
- 상단 벽·바닥 경계와 하단 근경 벽은 카메라가 상하로 추적되더라도 바로 바깥이 드러나지 않게 배치합니다.
- 근경 벽은 월드 오브젝트이므로 카메라가 멀리 상하 이동하면 화면 밖으로 이동할 수 있으며, 그 아래에도 이동 바닥이 이어져야 합니다.

## 제출용 출처 기록

- AI 생성 에셋은 생성 도구, 프롬프트 의도, 투명 처리 방법을 `docs/asset-production/`에 기록합니다.
- 원본 생성 파일과 폐기안은 저장소 밖의 개인 작업 공간에 보관하고 Git에는 포함하지 않습니다.
