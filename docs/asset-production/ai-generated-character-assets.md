# AI 생성 캐릭터 에셋 기록

## 생성 개요

- 생성일: 2026-07-26
- 생성 도구: Codex 내장 `imagegen`
- 생성 방식: 내장 이미지 생성 후 녹색 크로마키 제거
- 외부 참조 이미지: 없음
- 사용 목적: `Dev_PantryBackground` 개발 씬의 플레이어와 프로토타입 적 표현

## 컨셉시트

- 파일: `Assets/_Project/Art/Concepts/Characters/CatMouse_CharacterConcept_v1.png`
- 방향:
  - 동화풍 식료품 저장실에 어울리는 2D 손그림 게임 아트
  - 짙은 갈색 외곽선과 부드러운 과슈 질감
  - 빠른 횡스크롤 화면에서도 구분되는 단순한 실루엣
  - 크림색 쥐, 주황색 기본 고양이, 청록색 스카프의 속공 고양이, 목재 갑옷의 중장 고양이
- 주요 프롬프트:

```text
동화풍 식료품 저장실을 배경으로 하는 빠른 횡스크롤 게임의 캐릭터 컨셉시트.
플레이어 쥐 1종과 기본형·속공형·중장형 고양이 3종을 동일한 측면 시점과
일관된 팔레트, 짙은 갈색 외곽선, 부드러운 과슈 질감으로 표현한다.
작은 화면에서도 읽히는 실루엣을 사용하고 글자, 로고, 워터마크는 넣지 않는다.
```

## 후처리와 Unity 적용

- 프로젝트 외부의 생성 원본은 제출 소스에 포함하지 않습니다.
- 최종 PNG는 `remove_chroma_key.py`의 경계 샘플링, 소프트 매트와 디스필 처리로 배경을 제거했습니다.
- 캐릭터 내부의 그림, 색상과 형태는 별도로 합성하거나 수정하지 않았습니다.
- Unity에서는 `Sprite (2D and UI)`, `Single`, 하단 중앙 피벗, Bilinear 필터, Mipmap 비활성으로 가져옵니다.
- 플레이어 높이는 1유닛이며 적은 기본형 1.0, 속공형 0.85, 중장형 1.25유닛을 기준으로 표시합니다.
- 달리기 느낌은 프레임 합성이 아니라 시각 자식 Transform의 상하 바운스와 미세 회전으로 표현합니다.

## 권리와 제출 시 확인

- 특정 게임의 캐릭터, 로고 또는 추출 에셋을 입력 참조로 사용하지 않았습니다.
- 제출 전 사용 중인 이미지 생성 도구의 최신 이용 약관과 공모전 표기 요건을 다시 확인합니다.
