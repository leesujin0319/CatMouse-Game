# 개발 테스트 러너 v0.1

`Dev_PantryBackground` 씬에서 배경·카메라·입력·HUD의 연결을 검증하기 위한 임시 플레이어입니다.

## 동작

- 자동 전진: 오른쪽으로 초당 `3.5 Unity units` 이동합니다.
- 거리 표시: `1 Unity unit = 10m`로 환산해 상단 HUD에 `0000 m` 형식으로 표시합니다.
- 상승: 마우스 또는 터치 입력을 누르는 동안 위로 이동합니다.
- 하강: 입력을 놓으면 아래로 이동합니다.
- 세로 속도: 초당 `5 Unity units`입니다.
- 이동 경계: `Y -3.4`부터 `Y 1.75`까지만 이동합니다.

## 씬 연결

- `TestMouse`의 Transform과 스프라이트 피벗은 모두 하단 기준입니다.
- `CameraRigTarget`과 `ScrollDriver`는 `TestMouse`의 자식으로 연결됩니다.
- Cinemachine은 `CameraRigTarget`을 추적하므로 캐릭터의 수평·수직 이동을 함께 따라갑니다.
- 배경 레이어는 카메라 상대 패럴랙스로 동작합니다. 기존의 원경·바닥·근경 속도 계수(`0.20`, `0.72`, `0.95`)는 화면에서의 상대 스크롤 비율로 유지됩니다.
- 하단 근경은 Sorting Order `100`이며 충돌체가 없습니다. 캐릭터보다 앞에 표시되지만 이동을 방해하지 않습니다.

## 입력 구현

- Unity Input System의 `InputAction`을 사용합니다.
- 바인딩: `<Pointer>/press`
- 마우스와 터치가 같은 상승 입력으로 처리됩니다.

## 검증 항목

- 플레이 모드에서 TestMouse가 우측으로 이동하며 거리 HUD가 증가하는지 확인합니다.
- 입력을 유지했을 때 상단 경계에서 더 이상 상승하지 않는지 확인합니다.
- 입력을 놓았을 때 하단 경계에서 더 이상 하강하지 않는지 확인합니다.
- 캐릭터 이동 시 Cinemachine과 세 배경 레이어가 함께 이동하는지 확인합니다.
