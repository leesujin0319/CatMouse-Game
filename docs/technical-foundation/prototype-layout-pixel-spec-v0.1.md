# 개발 배경 프로토타입 픽셀 레이아웃 v0.1

## 기준

- 기준 해상도: `1920 × 1080` (가로 16:9)
- Unity 단위: `100 PPU` (`100px = 1 Unity unit`)
- 기본 카메라: Orthographic Size `5.4` (세로 10.8 units = 1080px)
- 아래 Y값은 화면 위에서 아래로 내려오는 픽셀값입니다.

## 최초 화면의 레이어 구조

| 레이어 | 화면 Y 범위 | 높이 | 역할 | 프로토타입 색 |
| --- | ---: | ---: | --- | --- |
| 상단 벽 | 0–300px | 300px | 이동 바닥의 상단에 맞닿는 배경 벽 | `#C9D6DC` |
| 이동 바닥 | 300–1080px | 780px | 캐릭터가 이동하는 기본 바탕 | `#3B4E57` |
| 하단 근경 벽 | 920–1080px | 160px | 바닥 위를 40px 덮는 비충돌 오버레이 | `#6F7F89` |

- 상단 벽의 하단과 이동 바닥의 상단은 `Y 300px`에서 맞닿습니다.
- 하단 근경 벽은 바닥의 하단 `40px`를 시각적으로 덮습니다. 충돌체를 두지 않으므로 플레이어 이동을 막지 않습니다.
- 플레이어 기본 이동 안전 영역은 바닥 내부 `Y 360–880px`입니다.

## 렌더링 우선순위

| 대상 | Sorting Order | 비고 |
| --- | ---: | --- |
| 상단 벽 | -220 | 플레이 영역 뒤 |
| 이동 바닥 | -140 | 플레이 영역 뒤 |
| 플레이어 기본값 | 0 | 이후 캐릭터 스프라이트 기준 |
| 하단 근경 벽 | 100 | 플레이어보다 앞에 표시 |
| 근경 격자 오버레이 | 101 | 근경 벽 위에만 표시 |

근경 레이어에는 `Collider`, `Collider2D`를 두지 않습니다.

## 카메라 추적을 위한 월드 커버리지

| 레이어 | 실제 커버리지 | 기준 화면에서의 경계 |
| --- | ---: | --- |
| 상단 벽 | 1920 × 1620px | 하단이 Y 300px |
| 이동 바닥 | 1920 × 1380px | 상단이 Y 300px |
| 하단 근경 벽 | 1920 × 600px | 상단이 Y 920px |

상단 벽은 기준 화면보다 충분히 높게 확장하여, 카메라가 위로 추적될 때 카메라 배경색이나 별도 뒷배경이 노출되지 않도록 합니다. 세 레이어 모두 수평 반복되며, 현재는 단색 바탕과 Kenney 격자 오버레이만 사용합니다.
