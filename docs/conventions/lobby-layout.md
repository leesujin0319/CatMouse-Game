# 로비 레이아웃 기준 v4

## 기준

- 기준 해상도는 `1920×1080 px`입니다.
- Canvas Scaler는 `Scale With Screen Size`, Match 값은 `0.5`입니다.
- 모든 크기·간격·좌표는 `8 px`의 배수로 관리합니다.
- 로비는 인게임 HUD를 표시하지 않습니다. 치즈, 플레이어 대기 화면, 메타 메뉴, 게임 시작만 배치합니다.

## 우측 드로어와 슬롯

강화·장비·설정은 화면 전체를 어둡게 덮는 모달이 아니라 우측 드로어로 엽니다. 메뉴 탭은 드로어의 우측 레일로 남아 있으므로 메뉴를 바꿀 때 로비 맥락을 잃지 않습니다.

| 요소 | 크기·간격 | 기준 |
| --- | ---: | --- |
| 드로어 | 912×760 | 우측 중앙 `(-496, 0)` |
| 메타 슬롯 | 600×136 | 드로어 내부 좌측으로 128 px 이동 |
| 첫 슬롯 | 상단에서 240 px | 제목·안내문과 분리 |
| 슬롯 간격 | 168 px | 3개 슬롯 공통 |
| 슬롯 행동 버튼 | 168×56 | 슬롯 우측, 주황색 주 행동 |

- 슬롯은 얇은 단선·평면 중심의 정보 단위입니다. 기존의 두꺼운 목재 프레임이나 다중 테두리를 사용하지 않습니다.
- 장비는 장착 중인 항목만 청록색 선택 슬롯을 사용합니다. 다른 장비는 중립 슬롯으로 유지합니다.
- 제목·설명·아이콘·버튼 라벨은 모두 별도 UI 요소이며, 이미지에 문구를 합성하지 않습니다.

## 수정 위치

- 화면 크기와 좌표: `LobbySceneInstaller.LobbyLayout`
- 드로어·슬롯 생성: `LobbySceneInstaller.CreateDrawer`, `CreateMetaSlot`
- 실제 표시 데이터와 선택 상태: `LobbySceneController`
- 강화·장비 데이터: `MetaProgressionCatalog.asset`
