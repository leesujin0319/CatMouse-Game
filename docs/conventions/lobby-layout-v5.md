# 로비 UI 레이아웃 v12

## 목적

로비 화면을 임시 패널의 집합이 아니라, 캐릭터 무대와 고정 메뉴 그리고 메뉴별 작업 영역이 구분된 모바일 게임 화면으로 구성합니다.

## 기준

- 기준 해상도: `1920×1080 px`
- 기준 단위: 모든 크기, 여백, 좌표는 `8 px`의 배수입니다.
- 캐릭터와 게임 시작은 좌측 무대에만 배치합니다.
- 영구 강화, 장비 착용, 설정은 우측의 고정 메뉴 레일에 배치합니다.
- 강화, 장비 착용, 설정은 각각의 작업 패널을 여는 행동 메뉴입니다. 선택 상태를 유지하지 않습니다.

## 레이아웃 편집 절차

1. Project 창에서 `Assets/_Project/Data/UI/LobbyLayoutProfile.asset`을 선택하거나 `CatMouse > UI > Select Lobby Layout Profile`을 실행합니다.
2. Inspector에서 배치·크기·여백 값을 수정합니다. 값은 `Grid Unit`의 배수로 자동 보정되며, Game View 가이드도 즉시 갱신됩니다.
3. 가이드로 모듈·요소의 경계와 중첩 관계를 확인합니다.
4. 변경한 영역에 맞는 개별 적용 버튼을 누르거나, 여러 영역을 수정했다면 `전체 로비 UI 적용`을 누릅니다.

- 로비의 조정 가능한 위치·크기·여백 값은 `LobbyLayoutProfile`만 사용합니다.
- `LobbySceneInstaller`에는 레이아웃 수치를 직접 작성하지 않으며, 프로필을 읽어 씬을 생성합니다.
- Inspector 적용 버튼은 `LobbyLayoutProfileEditor`가 제공합니다. 개별 적용은 `LobbyScene`을 연 상태에서만 실행합니다.
- 레이아웃 가이드는 금색(무대), 청록색(내비게이션), 보라색(작업 패널)으로 구분합니다. 프로필 값 변경 시 즉시 움직이는 편집용 임시 오버레이이므로 저장·빌드에 포함하지 않습니다.

## 모듈 프리팹 구조

```text
Assets/_Project/Prefabs/UI/Lobby/Modules/
├── Stage/LobbyStage.prefab
├── Navigation/LobbyNavigation.prefab
└── Panels/
    ├── LobbyPanel_Upgrade.prefab
    ├── LobbyPanel_Equipment.prefab
    └── LobbyPanel_Settings.prefab
```

| 모듈 | 포함 요소 | 개별 적용 |
| --- | --- | --- |
| `LobbyStage` | 배경, 재화, 캐릭터 미리보기, 게임 시작 | `무대 적용` |
| `LobbyNavigation` | 우측 메뉴 도크, 강화·장비·설정 버튼 | `내비게이션 적용` |
| `LobbyPanel_Upgrade` | 영구 강화 패널과 성장 행 | `영구 강화 패널 적용` |
| `LobbyPanel_Equipment` | 장비 착용 패널과 장비 행 | `장비 착용 패널 적용` |
| `LobbyPanel_Settings` | 설정 패널과 볼륨 조절 | `설정 패널 적용` |

- 개별 적용은 대상 모듈 프리팹과 대상 씬 모듈만 재생성하고, `LobbySceneController`의 해당 참조만 다시 연결합니다.
- 전체 적용은 다섯 모듈과 로비 씬을 함께 갱신합니다.

| 영역 | 크기 / 위치 | 역할 |
| --- | --- | --- |
| 캐릭터 무대 | 480×480, 중앙 `(-448, -8)` | 로비의 주 시선 |
| 게임 시작 버튼 | 640×128, 하단 중앙 `(-400, 160)` | 런 시작 |
| 메뉴 도크 배경 | 400×1080, 우측 중앙 `(-200, 0)` | 우측 빠른 메뉴의 공통 배경 |
| 빠른 메뉴 도크 | 336×128, 우측 중앙 `(-200, 192 / 0 / -192)` | 고정 행동 메뉴 |
| 작업 패널 | 640×720, 우측 중앙 `(-720, 0)` | 실행한 메뉴의 콘텐츠 |
| 콘텐츠 행 | 544×120, 첫 행 상단 184, 행 간격 136 | 메타 성장 또는 장비 정보 |

## 레이아웃 규칙

- 모든 수치는 `8 px` 단위만 사용합니다.
- 우측 메뉴 도크는 폭 `400 px`, 좌우 내부 여백 `32 px`입니다. 메뉴 버튼 폭은 항상 `336 px`이며, 도크 중앙에 배치합니다.
- 메뉴 항목은 높이 `128 px`, 항목 간 간격 `64 px`를 사용합니다. 세 항목의 중심 Y 좌표는 `192 / 0 / -192`로 고정합니다.
- 메뉴의 아이콘은 좌측 `64×64 px` 영역에 배치하고, 레이블은 아이콘 영역과 `16 px` 간격을 제외한 콘텐츠 영역에서 가운데 정렬합니다.
- 시작 버튼은 좌측 아이콘 영역 `160 px`만 제외한 콘텐츠 영역에서 레이블을 가운데 정렬합니다. 우측에는 추가 여백을 두지 않습니다.
- 강화·장비 착용·설정 메뉴는 동일한 크림색 9-슬라이스 배경을 사용하는 행동 버튼입니다. 패널을 열어도 메뉴 자체는 강조하지 않습니다. 민트선·화살표·추가 장식은 사용하지 않습니다.
- 버튼 배경은 계층 구분에만 사용합니다. 게임 시작은 골드 9-슬라이스, 메뉴 행동 버튼은 크림 9-슬라이스, 패널 콘텐츠 행은 기존 슬롯 9-슬라이스를 사용합니다.
- 작업 패널과 메뉴 도크 사이는 `40 px`를 유지하며, 모든 버튼은 누를 때 `0.96배`로 축소됩니다.

## 수정 위치

- 씬 생성과 프로필 적용: `LobbySceneInstaller`
- 레이아웃 데이터: `LobbyLayoutProfile`
- Inspector 적용 버튼: `LobbyLayoutProfileEditor`
- 메뉴 실행과 패널 전환: `LobbySceneController`
- 드로어 진입 연출: `LobbyDrawerMotion`
- 버튼 눌림 연출: `LobbyButtonPressFeedback`
