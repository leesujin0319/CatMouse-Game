# 로비 UI 레퍼런스 검토 v1

## 목적

식료품 저장실 배경을 유지하면서, 가로형 런게임 로비에 맞는 미니멀한 게임 UI 원칙을 정리합니다. 아래 자료는 화면 구조와 정보 밀도만 참고하며, 이미지·아이콘·폰트 등 외부 리소스는 프로젝트에 사용하지 않습니다.

## 비교 레퍼런스

| 레퍼런스 | 취할 점 | 배제할 점 |
| --- | --- | --- |
| Soul Knight Prequel 메인 허브 | 배경 속 캐릭터 무대와 우측 기능 진입의 공간 분리 | 이벤트와 기능 아이콘을 과도하게 나열하는 방식 |
| Survivor.io 로비 | 하나의 강한 게임 시작 행동과 최소한의 재화 표시 | 상단·하단 HUD를 동시에 사용하는 높은 정보 밀도 |
| Archero 계열 장비 화면 | 캐릭터·장비·행동을 읽는 명확한 시선 흐름 | 장비 슬롯을 캐릭터 주변에 모두 배치하는 복잡한 구성 |

## 적용 방향

- 로비 기본 화면에는 재화, 캐릭터, 게임 시작, 세 개 메뉴만 표시합니다.
- 비선택 메뉴는 반투명한 배경만 유지하고, 선택된 메뉴와 게임 시작 버튼에만 명확한 색과 깊이를 부여합니다.
- 장비와 강화 정보는 메뉴를 누른 뒤 작업 패널에서만 표시합니다.
- 작업 패널은 하나의 밝은 카드로 유지하고, 내부 행은 낮은 대비의 목록으로 처리합니다.
- 색상 역할은 주황색(게임 시작·확정), 청록색(선택·장착), 갈색(보조)으로 제한합니다.

## 구현한 허브 구조

- 기본 화면의 우측 메뉴는 배경 위에 떠 있는 세 개의 빠른 진입 항목입니다.
- 비선택 메뉴는 아이콘과 레이블만 보이며, 카드 배경을 표시하지 않습니다.
- 선택한 메뉴만 밝은 패널로 확장되고, 콘텐츠 패널은 그 왼쪽에서 진입합니다.
- 게임 시작 버튼은 캐릭터 무대 아래에서 독립된 주 행동으로 유지합니다.
